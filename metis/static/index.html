How Metis works

When something breaks in production, evidence comes from many places: source control, build systems, deployment logs, and runtime probes. Some arrive late. Some contradict each other.

Metis figures out what was actually running at the time of the incident by cross-checking all these records. It flags contradictions and gaps, then hands a clean picture to Gemini AI.

The key insight: a recovery system that doesn't know what's actually running will suggest invalid fixes 40-60% of the time (per the R2Act research paper). Metis brings that to 0%.
